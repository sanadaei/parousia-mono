# アセットと表示のアートディレクション

目標は、惑星から足元まで**本物らしく**見えること。様式化（トゥーン・ローポリ強調）はしない。形は少ないポリゴンで済ませるが、比率と色は実物に合わせる。

## 共通の約束（全アセット）
- 単位はメートル。**Y上向き**、原点は地面の中心（接地点）、正面は **+Z**。
- テクスチャは使わず**頂点色**だけ（sRGB 0..1）。マテリアルは1種類（金属0、粗さ1）。エンジン側で差し替えられる。
- 生成は `(seed, params) => Mesh` の純関数。同じseedなら同じ形。
- 三角形の上限（LOD0）: 樹木 1500、低木 300、草 60、岩 400、小建物 1500、大建物 3000、橋 3000。LOD1（遠景用）は上限の約1/8。
- 書き出しは glTF 2.0（.glb、`COLOR_0`）。`node terrain/tools/export-assets.mjs` で `terrain/out/assets/` に出る。

## 色（実物のアルベドに近い、彩度を抑えた値）
| 用途 | 色 | 用途 | 色 |
|---|---|---|---|
| 樹皮（一般） | `#5a4632` | 白樺の樹皮 | `#d6d1c4` |
| 針葉 | `#2c4429`〜`#3a5233` | 広葉（夏） | `#4a6a2c`〜`#5d7a34` |
| 草（湿） | `#6f8338` | 草（乾） | `#a89a5c` |
| 土・道 | `#7d6a52` | 岩（花崗岩） | `#8c857b` |
| 岩（暗色） | `#5e5a55` | 漆喰 | `#d8cdb8` |
| 木材 | `#6b4a2e` | 石積み | `#9a9284` |
| 瓦（素焼き） | `#94604a` | スレート | `#4b5056` |
| 茅葺き | `#9a8150` | 窓・開口 | `#252b33` |

- 同じ種類の個体ごとに、明度±8%と色相を少しずらす（`rng(seed)`）。
- 下ほど暗くする（簡易AO）。樹冠の内側、軒下、窓の奥などは0.6〜0.8倍。

## 表示（プレビュー）
- 光: 太陽（色温度約5500K）と天空光（上から青、下から地面の照り返し）。影あり。
- トーン: フィルム調のトーンマップ（ACES近似）とsRGB。白飛びさせない。
- 空気遠近: 高度で薄くなる大気。遠景は青く淡く、太陽側は暖色。
- 地表: 傾斜で岩、高度と気温で雪、植生は気候から。画素より細かい起伏は法線で表す。

## アセット一覧（必要なものと状態）
| 分類 | 種類 | 用途（ロードマップ） | 状態 |
|---|---|---|---|
| 植生 `vegetation.mjs` | トウヒ、マツ、広葉樹、白樺、ヤシ、低木、草むら、枯れ木 | T3 土地被覆（森林、草地、熱帯、森林限界） | 初版 |
| 建物 `buildings.mjs` | 小さな家、農家、納屋、町家（連棟用）、教会、倉庫、井戸 ×4様式（木骨、石、地中海、北欧） | T4 村・町 | 初版 |
| 橋 `buildings.mjs` | 石のアーチ橋、木の桁橋 | T4 道路の渡河 | 初版 |
| 小物 `props.mjs` | 岩、崖錐の石、木の柵、石垣、道標 | T1 岩場、T4 農地の区画・道 | 初版 |
| 目印 `landmarks.mjs` | 城壁、壁の塔（円・角）、門楼、風車（塔型・柱型）、水車小屋 | T4 町・村 | 初版 |
| 水辺 `waterfront.mjs` | 桟橋、石の岸壁、手漕ぎ舟、漁船、コグ船（水面 y=0） | T4 港 | 初版 |
| 作物 `crops.mjs` | 麦畑、野菜畑、ぶどう畑（区画タイル、+X方向の畝）、干し草の山、ロール | T3/T4 農地 | 初版 |
| 道路 `roads.mjs` | `roadRibbon(path, { kind, ground })`: 轍の農道・砂利道・石畳の街道。中心線は地面を道に沿ってならし、外縁で地面へなじませる | T4 道路網 | 初版。側溝は地形の下に隠れる（地形の切り盛りはT4の編集層） |
| 雲 `render/look.mjs` | 積雲の層（高度約2km、`clouds=0..1`） | 表示 | 初版 |

- 確認方法: `node terrain/tools/export-assets.mjs` → `node terrain/tools/serve.mjs` → `http://127.0.0.1:8787/preview/gallery.html`（`?cat=vegetation` など）。スクリーンショットは `node terrain/tools/shoot-page.mjs out.png 'preview/gallery.html?cat=props'`。
- 表示の共通部分は `render/look.mjs`（空・太陽光・空気遠近・トーンマップ）。地形プレビューとギャラリーで同じものを使う。
