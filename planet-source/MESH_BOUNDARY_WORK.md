# 水際・道路際の表示メッシュ生成時間

境界を切り出す二分探索を、隣接三角形ごとに重複実行していた。
同じ端点対を正規順序で一度だけ探索し、1タイルにつき最大2,048辺まで保持する。
キャッシュはそのタイルの生成終了で破棄され、世界の保存や数値場は変わらない。

また、小さな辺も18回探索していた処理を、球面上の移動距離上限から表示上1mmの
目標精度に必要な回数へ減らした。長い辺では従来の18回を維持する。
これは描画境界の近似精度であり、Coreの地盤・水深を丸めるものではない。

実際の生成世界の同じ川・橋を含むL12/L14/L16の3タイルで比較した。

- 表面sample呼び出し: 28,938 → 21,015（約27%減）。法線用の地盤参照はこの数に含まない
- 地盤頂点のFloat32配列: 完全一致
- 表示オーバーレイの頂点数・接続: 一致
- 表示オーバーレイの位置差: 最大約0.85mm
- 1回の直列測定: 合計約9.14秒 → 7.00秒

同じホストで別のブラウザ連続試験も動いていたため、時間差を恒常的な速度保証にはしない。
実入力のworldId、タイル、各呼出回数、出力と時間は
examples/planet/verification/mesh-boundary-work.json に保存した。
通常ブラウザのWorker統計にも最後のメッシュ生成時間と探索回数を記録する。
全GPUや全世界の表示速度、ストリーミング待ち時間の完了判定とは別。
