# 集落ラベル・操作・seed生成

## 入口
`npm start`（scripts/start-planet.mjs）で起動し、全球画面を開く。
更新前からサーバーを起動していた場合は一度終了して起動し直す。

- 集落名と保存済みIDを遠景にも表示。クリックで集落へ移動。地球の裏側は非表示。
- IDは元データの settlement:<cellIndex> を維持。別の惑星をまたぐ識別は世界IDと組み合わせる。
- ドラッグはユーザー指定に合わせ、右で東、下で南へ視点を移動。回転した視点にも対応。
- seed生成を開き、1〜128文字を入力。生成処理は別プロセス・最大256MiBヒープ・同時1件・180秒上限。
- 保存済みの同じseedは再利用。現在の世界や既存出力を上書きしない。生成結果のリンクから開く。
- 結果は examples/planet/seeds/<seedと生成プロファイルのハッシュ>/ に保存。Gitには自動追加しない。
- 生成プロファイル v1 は既存の標準128×64ソース解像度、最大8集落。他の設定は現在固定。
- メモリ不足時は生成を拒否。失敗した部分出力を成功扱いせず、再実行で上書きしない。
- 静的ホスティングだけでは生成不可。ローカル起動サーバーが必要。

## データの有無
- 標高: 保存された数値場あり。3D起伏・標高色・中心点の地盤高表示あり。実寸1倍で遠景の山は小さい。
- 等高線: 全球画面未実装。src/ui/map-viewer.mjs の別2Dビューには表示機能あり。
- 気温: この惑星生成器・保存形式に気候温度場なし。日照方向は気温ではない。
- 居住適性: 全球の総合適性場なし。集落候補を標高・勾配・水辺等で選ぶロジックはある。生産・気候・食料を統合した評価ではない。

地形生成は手続き的な近似であり、プレートテクトニクス・気候・人口モデルの実装完了を意味しない。
