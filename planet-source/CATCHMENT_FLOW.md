# 地形からの集水範囲と排水管候補

2026-10-10。`src/core/catchment-flow.mjs` / `planet-catchments.mjs`。
雨水画面の「集水範囲と管径候補を調べる」から同じ保存世界を計算Workerへ渡す。
中断はWorkerを終了し、雨水の最後の状態を維持する。

## 入力と出力

- 入力: 保存worldId、集落ID、固定セル間隔、明示した雨量・継続時間・流出係数・移動速度、入口/出口水深、候補径、安全係数。
- 世界の造成前の地盤（全球河床を含む）を集落の700m四方から取得。カメラ・LOD・表示メッシュは使わない。
- 厳密な下降のみのD8受け手を選び、入口が含まれるセルへ流下する面積と最長経路を算出。地形を書き換えず、窪地を勝手に埋めない。
- 外周へ続く集水範囲、平坦部、領域外の入口は未確定。部分面積からの数値は参考値で、管径選定へ通さない。
- Q = C × i × A（iをm/秒に換算）。速度を明示入力し、経路長/速度と10分の長い方より降雨が短ければ条件外。80haを超える範囲も対象外。
- 粗さを2倍に変えた集水範囲も計算。面積の相対差が25%超、またはどちらか未確定なら、単一格子の計算候補を記録に残しても最終候補は返さない。
- 成立した入力だけを既存の円形管モデルへ接続。保存された管の径と雨水計算の状態は変えない。

## 実データで分かった限界

`npm run verify:planet-catchments` の実入力・実出力を
`examples/planet/verification/catchments.json` に保存。
3集落を5m/10mで比較したところ、入口の含まれる1セルへの集水は間隔に非常に敏感だった。
標準5mでは3集落10本のすべてが2解像度一致条件を満たさず、最終管径候補は0本。
例えば最初の村の2本目は5mで2150m²、10mで4300m²かつ外周に達する。
10m/20mでは3本が数値条件を満たしたが、これを高精度での収束・実用設計の証明にはしない。
このため、固定0.4mの管を自動縮小する変更は行わない。

次に必要なのは、道路・側溝による捕捉範囲を点でなく境界として扱い、入口へどう集めるかの設計。
地下水・窪地の越流・貯留・全球からの外部流入・降雨頻度・実測校正は未実装。
2解像度一致も十分条件ではなく、明らかな不一致を排除する診断に限る。
雨水の時間発展とこのピーク近似は別であり、ピーク流量をハイドログラフや雨の全体積に流用しない。

## 参考にした制限

TxDOT Hydraulic Design Manual, Rational Method, Assumptions and Limitations:
https://www.txdot.gov/manuals/des/hyd/chapter-4--hydrology/section-12--rational-method/assumptions-and-limitations.html

均一な降雨・到達時間・貯留を扱わないという適用条件を参照した。
移動速度、流出係数、25%の比較しきい値は本実験の明示仮定で、同資料による校正値ではない。

## 2026-10-10: 点から明示した集水線へ

`collectorWidthM`（0〜200m、既定0）で、管の入口を横切る理想集水線を指定できる。
0は従来の入口セル。正の幅は管軸に直交し、入口を中央とする線を比較実験の入力にする。
線と交差する全セル（格子境界では両側）を取り、その上流の和集合を計算する。
重複した分岐・折り返し線を二重加算しない。新しい明示線モードは `sampled-d8-catchments@2`。
上流経路に線全長を加えた保守的な移動距離を使い、外周・平坦部・2解像度差の拒否は残す。

これは水を確実に捕捉して入口へ運ぶという仮定。側溝の勾配・施工・流下能力を証明せず、
保存世界へ側溝を勝手に足さない。候補径はこの仮定付きの比較結果であり、施工径を変更しない。
Core/Worker/実画面を接続し、緑の破線を表示。幅や雨などの入力変更で以前の結果を消去する。

実3村×0/20m幅×5/10m格子を `collectors.json` に保存。5m/10m比較では0m幅の候補0本に対し、
20m幅では2本が25%以内に入る。ただし、その2本も10m/20m比較では一致しない。
したがって「収束した」「側溝を付ければ解決する」とは結論しない。
実画面の第1村20mでは0.0875haの管に条件付き0.2m候補、残る3本は解像度不一致。
`browser-collectors.json` が実出力。保存済みの直径0.4mや雨水状態は変えていない。

次は、この仮定を実際の集水地形/側溝の縦断と能力へ接続すること。現在の線は診断用である。
