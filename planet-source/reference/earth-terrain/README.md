# 地球の地形を使った参照・分類

2026-10-11。これは取得済みの参照データと分類の整理であり、これらの地形を生成器がすべて実装済みという意味ではない。

## 一つの分類名で全部を決めない

- 広域の形：平野、丘陵、山地、台地、地形的な盆地。
- その中の部分：山頂、尾根、肩、斜面、谷、斜面下端、くぼ地、平坦面。探索する距離によって同じ場所の分類は変わる。
- 成り立ち：河川、氷河、海岸、風、火山、地殻変動、溶食、斜面崩壊など。高さの形だけで成因を断定しない。

例えば「台地の端の崖」「山地の中の平らな谷底」を同時に表せる必要がある。森・農地・町は地形と別の被覆・利用情報。洞窟や張り出した岩は一地点一標高の表現だけでは足りない。

## 実際に取得したもの

1. NOAA ETOPO 2022：アルプス、グランドキャニオン、オランダ、トスカーナ、富士山周辺、フィヨルドランドの各約0.5度四方。各121×121標高点、全6件で約3.6MB。取得時のURL・バイト数・SHA-256を保存。
2. Terrain22：地域21・23・57の分類GeoTIFF。ZIP計約70MB。欧州・ニュージーランドのサンプルを窓読み込みし、600×600の分類図を作成。地球全体の巨大な配列は読み込まない。
3. Terrain22の正式な22群と色設定を catalogue.json に保持。日本語名はこのプロジェクトの訳。Geomorphonsの10形状は別体系として記録し、混同しない。

ETOPOは15秒角で、今回の南北間隔は約463m。広域の谷・山並みの比較には使えるが、数m〜数十mの崖や村外れの丘の最終判定には粗い。Terrain22は約90m級の形状分類で、標高データではない。「Cliff slope」もすべて垂直な崖であるという意味ではない。

Terrain22の0は欠測・マスク。平地や海という断定に置き換えない。凹地フラグは湿地やカルストの証明ではない。出典が注意するタイルの隙間も保持する。現在のオランダには干拓等があり、中世の自然地形を直接示す資料としては扱わない。

## 比較の条件

地球と生成地形を、同じ水平解像度・同じ距離の観測窓・類似する地形条件で比較する。5m差分で測った生成地形の傾斜と、約463mのDEM傾斜をそのまま比べない。傾斜分布に加え、起伏量、尾根と谷のつながり、平坦面と崖の隣接、排水との整合を確認する。参照地点は意図的に多様な場所を選んだもので、地球全体の割合の推定標本ではない。

## 再取得

`python scripts/fetch-earth-references.py /path/to/cache`

分類図も必要なら末尾に `--classification`。ハッシュ一致を確認し、違う既存ファイルは上書きしない。大きな原本はGitHubに同梱しない。分類図の窓読み込みにはrasterio等を利用できる。

## 出典・利用条件

- [NOAA NCEI ETOPO 2022](https://www.ncei.noaa.gov/products/etopo-global-relief-model)、[DOI 10.25921/fd45-gt74](https://doi.org/10.25921/fd45-gt74)。[今回の配信元と利用条件](https://coastwatch.pfeg.noaa.gov/erddap/griddap/ETOPO_2022_v1_15s.html)。無償利用・再配布可能、無保証。
- Iwahashi and Yamazaki (2022), [DOI 10.1186/s40645-022-00487-2](https://doi.org/10.1186/s40645-022-00487-2)。[Terrain22](https://gisstar.gsi.go.jp/terrain2021/)、公開元表記はCC-BY 4.0。今回の派生処理は範囲切出し・最近傍再投影・集計。分類の原番号と出典を保持。
- [GRASS r.geomorphon](https://grass.osgeo.org/grass-stable/manuals/r.geomorphon.html)：局所形状分類の参照。現段階で分類器の実装・移植はしていない。
- [USDA NRCS Geomorphic Description System](https://www.nrcs.usda.gov/resources/guides-and-instructions/geomorphic-description-system)：分類をスケールと成因で整理する参照候補。本文PDFは今回未精読。

30m級のCopernicus DEMも候補だが、建物や植生を含むDSMであり裸地の地形とは限らない。今回の取得済み原本には含めていない。

## 生成地形との実比較

`node scripts/compare-earth-reference.mjs WORLD.json /path/to/cache/alps.csv REPORT.json -10.546875 -18.984375`

実データの緯度・経度の刻みを中心緯度でメートル換算し、生成世界ではその同じ間隔で地表を取得する。両方に同じ中央差分を使用。今回のアルプス範囲と、生成世界の固定した山地域の比較は次のとおり。

| 対象 | 約38×56km内の標高差 | 傾斜中央値 | 傾斜95百分位 |
|---|---:|---:|---:|
| アルプス参照範囲 | 3852m | 23.0° | 38.3° |
| 従来の丸い地形 | 1043m | 7.0° | 16.0° |
| 岩棚の試作 | 1148m | 13.5° | 27.1° |

`reports/earth-alps-*-comparison-2026-10-11.json` が実出力。生成地点は先の有限調査で試作の傾斜が大きかった場所を意図的に選んだ。これは代表地点の無作為抽出ではなく、「全世界がアルプスの値になるべき」という基準でもない。標高を強調表示しても、この元データの比較値は変わらない。

現段階で使えているのは、参照の分類、実データ取得、同じ観測条件での数値比較まで。生成器への成因別の地形生成・自動選択の接続と、ゲーム画面での自然さの受入は未完了。

## 生成済み地形での局所形状判定

`src/core/landform-inspection.mjs` は既存の起伏移動先について、半径250m・2.5km・25kmの8方向を各16点読む。GRASS公開凡例の10形状の集約表を参照し、平坦面・頂部・尾根状・肩・張り出し・斜面・くぼんだ斜面・裾・谷状・くぼ地を返す。実装は連続地表を有限点で読む独自の簡易方式であり、GRASSのラスタ処理、補正、498パターン分類を移植・再現したものではない。Terrain22の22広域分類とも別物。

新しい生成manifestの起伏移動先を選択すると、範囲別の参考判定が表示される。旧manifestは従来表示のまま使える。地形・水・位置・世界IDを書き換えない。既存世界の実測6地点では、追加2310標高問い合わせ、クラウドで約0.46秒（元の移動先調査込み）だった。`reports/generated-landform-shapes-2026-10-11.json` が実出力。ブラウザでの受入確認は未実施。

頂部を探した移動先に偏るので、この6地点から世界の種類別割合は推定しない。観測半径と平坦判定角度に依存する幾何形状であり、「くぼ地だから湖」「谷だから川」「平坦面だから平野」とは決めない。成因は未判定。数値が欠けた方向があれば、その範囲全体を「判定できない」とする。

## 5m級の近景資料：河岸段丘と海食崖

国土地理院の典型地形リストにある沼田付近（河岸段丘）と屏風ヶ浦（海食崖）について、DEM5A標高PNGを各3×3タイル取得した。合計18枚、約1.3MB。`gsi-local-manifest.json` に元URL・取得時刻・サイズ・SHA-256・公式例の位置を記録。各約3km四方。元データは5m級で、ズーム15画素は中心緯度で約3.83/3.88m間隔に補間されるため、独立した3.8m測量とは扱わない。

実入力の復号・集計結果は `reports/earth-local-landforms-2026-10-11.json`。沼田の標高差236m、傾斜中央値3.19°、95百分位34.38°。屏風ヶ浦は63.62m、1.82°、30.22°。平坦な面と局所的な急斜面が共存する例であり、全地形をこの数値に近づける目標ではない。欠測画素は沼田7567・屏風ヶ浦75192。海面0mに補完せず、傾斜も必要な標高がある点のみを集計する。現代の造成を含み、中世の景観そのものではない。

再取得：`python scripts/fetch-earth-references.py CACHE --local-landforms`。検査：`python scripts/inspect-gsi-reference.py CACHE OUTPUT.json`（numpyとPillowが必要）。近景復号のオフライン3テスト、取得処理5テストを別に実行した。描画のため地形の配布物へ直接組み込む処理ではなく、生成器を比較する研究用資料。
